# Customer Evidence Matrix

Esta matriz registra evidências observadas na base atual de clientes da Creative Print.

A amostra histórica ainda é pequena e, portanto, os dados não devem ser utilizados para generalizar o comportamento de todo o mercado.

| Garagens de venda de carro | Maior grupo | Chaveiros | Alto | Não observada | Chaveiros / NFC / Displays NFC | Potencial | **Forte para produtos físicos** |

## Interpretação

A matriz deve ser utilizada para distinguir evidência observada de hipótese estratégica.

### Garagens de venda de carro

Representam atualmente o maior sinal de demanda por produtos físicos dentro da base analisada, especialmente em relação a chaveiros personalizados.

Entretanto, não foi observada recompra suficiente para afirmar que o segmento possui alto potencial de recorrência.

Também não existe evidência suficiente para afirmar que a demanda por produtos físicos se converte naturalmente em demanda pelas soluções digitais da Creative Print.

### Fotógrafos

Existem poucos casos, mas foram observados sinais de recompra de chaveiros personalizados.

Essa recorrência representa um sinal relevante, porém a amostra ainda é pequena para validar fotógrafos como ICP.

### Escolas de artes marciais

Existem poucos casos, com evidência de recompra de produtos físicos.

Assim como nos fotógrafos, o comportamento representa uma evidência parcial e precisa ser validado com uma amostra maior.

## Limitações da amostra

A base atual não possui volume suficiente para estabelecer relações estatisticamente significativas entre segmento, produto, recompra ou expansão digital.

Portanto:

- quantidade de clientes não equivale automaticamente a ICP;
- recompra em poucos clientes não equivale a padrão de mercado;
- potencial de expansão não equivale a demanda comprovada;
- ausência de evidência não significa ausência de demanda.

Os dados atuais devem ser utilizados como ponto de partida para formulação e teste de hipóteses comerciais.
